# التوثيق

| الملف | لمن | المحتوى |
|---|---|---|
| `SOLUTION_REPORT_AR.pdf` | الإدارة والفريق | ما أُنجز، البنية، الموديولات، **دورة العمل خطوة بخطوة**، الأمان والجودة، النشر، حدود وقرارات مفتوحة |
| `TRIAL_PLAN_AR.pdf` | العميل وموظفوه | خطة التجربة (١٤ يوماً)، المشاركون، التجهيز، القواعد، معايير النجاح، **٣٧ سيناريو حسب الدور**، الاستبيان، الورشة والقرار |
| `TRIAL_TRACKER.xlsx` | العميل وموظفوه | سجل نتائج السيناريوهات وملاحظاتهم واستبيانهم، مع ملخص يُحسب تلقائياً بمعايير النجاح |
| `DEPLOYMENT.md` | الفريق التقني | تجهيز أودو، النشر على حاوية بنطاق وHTTPS، التشغيل والنسخ الاحتياطي واستكشاف الأعطال |
| `PROJECT_CONCEPT.md` · `PHASE0_DESIGN.md` · `API_CONTRACT.yaml` | الفريق | الفكرة، التصميم الأول، وعقد واجهة `supply_api` |

إعادة توليد المستندات: `python3 docs/src/build_docs.py && node docs/src/print-pdf.mjs`
(المصدر: `docs/src/report.html`، و`docs/src/scenarios.py` مصدر واحد لخطة التجربة ولسجل النتائج).
